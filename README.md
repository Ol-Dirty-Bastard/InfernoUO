# Inferno - клиент

Скачай **[InfernoSetup.exe](https://github.com/Ol-Dirty-Bastard/InfernoUO/raw/main/InfernoSetup.exe)**,
запусти и нажми «Установить». Установщик скачает клиент, создаст ярлык
Inferno и откроет лаунчер. Дальше лаунчер сам обновляет игру при каждом
запуске.

В лаунчере укажи папку с файлами Ultima Online и добавь учётную запись.

Сайт шарда: https://playuo.ru
